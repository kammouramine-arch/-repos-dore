# Écran d'authentification premium (2026-09-15)

Refonte visuelle complète de l'entrée de l'application et des écrans qui la
suivent (connexion, inscription, mot de passe oublié, code de vérification,
onboarding entreprise). La logique d'authentification est inchangée : mêmes
appels, mêmes gardes de navigation, mêmes règles de rattachement Apple/Google.

## Ce qui a changé visuellement

| Avant | Après |
| --- | --- |
| Dégradé bleu plein écran, carte blanche posée dessus, boutons génériques. | Toile blanche, monogramme DEVISERA sur pastille blanche avec halo bleu très léger, titre en trois lignes « Vos devis. / Plus simples. / Plus rapides. », sous-titre gris. |
| Apple et Google dessinés à la main. | Apple : bouton natif `ASAuthorizationAppleIDButton` (type « Continuer », noir, coins 14). Google : traitement officiel du bouton clair (fond blanc, bordure `#747775` 1 pt, « G » quadrichrome, texte `#1F1F1F`). |
| E-mail au même niveau que les fournisseurs. | E-mail clairement secondaire : surface bleu pâle, bordure bleue douce, icône enveloppe ; séparé par un « ou » discret. |
| Champs bordés dans une carte. | Champs pleins gris clair, bordure bleue 1,5 pt à la prise de focus, libellés courts, aide sous le champ. |
| Écran de code : un champ texte. | Six cases, curseur dans la case active, confirmation automatique au sixième chiffre. |
| Onboarding : formulaire brut. | Barre d'étape « Étape 2 sur 2 », salutation au prénom transmis par Apple/Google, pastilles de métier, bouton principal et rappel du compte dans le pied de page. |

Ordre des trois options, dans les deux langues : Apple → Google → « ou » →
adresse e-mail → « Déjà un compte ? Se connecter ». Aucune quatrième option.

## Composants

`mobile/src/components/auth-kit.tsx` (nouveau) remplace `auth-surface.tsx` :

- `AuthScreen` : toile blanche, zones sûres (encoche, Dynamic Island, barre
  d'accueil), `KeyboardAvoidingView`, défilement si le contenu dépasse,
  chevron de retour dans une pastille de 40 pt, pied de page au-dessus de
  l'indicateur d'accueil, barre d'état sombre.
- `BrandMark` : monogramme sur pastille blanche, ombre bleue diffuse, halo.
- `AuthHeading` : surtitre facultatif, titre, sous-titre.
- `AuthField` : champ plein, focus animé, indice court en ligne, aide longue
  sous le champ, message d'erreur.
- `PrimaryAction` : bouton principal 56 pt (accent, doux ou contour),
  chargement intégré, état désactivé.
- `TextAction`, `OrDivider`, `Notice` (erreur, information, succès, avec
  fermeture), `StepProgress` (barre animée), `CodeInput` (six cases).
- `Entrance` et `Appear` : entrées animées (voir ci-dessous).
- `PressableScale` : pression animée avec retour haptique.

`mobile/src/components/social-buttons.tsx` (réécrit) : `AppleContinueButton`
(natif sur iOS, pastille noire « Connexion… » pendant l'authentification),
`GoogleContinueButton`, `EmailContinueButton`.

Écrans réécrits sur ce kit, logique intacte : `app/(auth)/index.tsx`,
`connexion.tsx`, `inscription.tsx`, `mot-de-passe.tsx`, `app/verification.tsx`,
`app/bienvenue.tsx`.

## Animations et retours

- Entrée : fondu + glissement de 14 pt vers le haut, 420 ms, easing cubique
  sortant, décalage de 55 ms par élément. Pilotée par des valeurs partagées
  Reanimated (`useSharedValue` + `withDelay` + `withTiming`), jamais par une
  animation de disposition : l'apparition d'un message d'erreur ou d'un état
  de chargement ne rejoue ni ne perturbe les éléments déjà en place.
- Pression : échelle 0,98 par ressort (amortissement 22, raideur 420), retour
  haptique léger (Apple, Google, e-mail), moyen pour le bouton principal,
  sélection pour les pastilles de métier.
- Aucun rebond, aucun zoom, aucun dégradé, aucune ombre décorative.
- Chargement : indicateur intégré dans le bouton concerné ; les autres
  options passent en opacité réduite et n'acceptent plus la pression.
- Double soumission : verrou par référence (`submitting`/`acting`) plus
  garde de 600 ms dans `PressableScale`.
- Annulation Apple/Google : retour silencieux à l'écran, sans message.
- Erreur Apple/Google : bandeau rouge fermable sous le sous-titre ; le
  bandeau ne suit pas l'utilisateur sur les écrans e-mail (ceux-ci n'affichent
  que les erreurs de leur propre soumission).

## Mode sombre

L'application est déclarée `userInterfaceStyle: 'light'` : iOS ne lui
transmet jamais l'apparence sombre. Les écrans d'authentification restent
donc clairs par conception, y compris sur un iPhone en mode sombre. Le bouton
Apple natif est forcé en noir pour rester lisible sur la toile blanche.

## À tester sur iPhone réel

1. Ouvrir l'application déconnecté : toile blanche, monogramme, titre sur
   trois lignes, trois options dans l'ordre Apple, Google, e-mail.
2. Entrée animée discrète (fondu + léger glissement), sans rebond.
3. iPhone en mode sombre : l'écran reste clair et lisible.
4. Petit écran (SE) : tout tient sans défilement ; Dynamic Island et Pro Max :
   marges et pied de page corrects, mentions légales au-dessus de la barre
   d'accueil.
5. Apple : pression → vibration légère → feuille système. Annuler revient à
   l'écran sans message. Confirmer → « Connexion… » dans la pastille noire →
   onboarding entreprise (nouveau compte) ou espace (compte connu).
6. Google : présent seulement si l'identifiant client iOS est configuré sur
   EAS (voir `AUTH_APPLE_GOOGLE_2026-09-15.md`). Même comportement qu'Apple.
7. « Continuer avec l'adresse e-mail » → inscription (Étape 1 sur 2), champs
   pleins, focus bleu, aide sous le mot de passe, « Créer mon compte » actif
   seulement quand le formulaire est prêt.
8. Code : six cases, clavier numérique, remplissage automatique depuis
   Messages/Mail (`oneTimeCode`), confirmation automatique au sixième chiffre.
9. Connexion : mauvais mot de passe → bandeau rouge sous le sous-titre ;
   double pression rapide sur « Se connecter » n'envoie qu'une requête.
10. Onboarding : prénom pré-rempli si Apple/Google l'a transmis, pastille
    de métier avec retour haptique, « Ouvrir mon atelier » actif dès que le
    nom de l'entreprise compte deux caractères.
11. Langue : iPhone en anglais → « Your quotes. / Simpler. Faster. »,
    « Continue with Apple / Google / email ».
