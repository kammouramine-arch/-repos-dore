# 4. THE HONEST PROBLEM — UK IS NOT THE EU

**Inkthreadable is UK-based.** For a French-established company selling to EU customers,
that is **still a customs border**.

| | |
|---|---|
| Ships to | **All European countries**, tracked via Royal Mail / DPD `[V]` |
| Production | 3–5 working days `[V]` |
| Shopify | Dedicated integration with its own fulfilment location `[V]` |
| **Customs into the EU** | **UK→EU is a third-country import.** Customs declaration, potential duty and import VAT `[A]` |
| **UK–EU trade agreement preference** | **Unlikely to apply.** Zero-tariff treatment requires qualifying UK/EU origin; these garments are manufactured in Asia, so preferential origin probably fails `[A — requires verification, do not act on this without confirming]` |

**So the choice is not "EU vs US". It is "which border".** UK→France is a shorter, faster,
cheaper border than US→France — but it is a border.
