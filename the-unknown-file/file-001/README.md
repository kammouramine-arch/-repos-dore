# THE UNKNOWN FILE — FILE #001 · Lake Nyos

This is the editable production project for both films: the vertical short (1080×1920, 30 fps) and the YouTube documentary (3840×2160, 24 fps). Every frame is generated by code from the sources in this folder, so any change re-renders deterministically.

## Folder map

| Path | What it is |
|---|---|
| `audio/` | The supplied ElevenLabs narration (originals, untouched) |
| `audio/master/` | Mastered narration, 48 kHz / 24-bit, about −14.5 LUFS and −1.3 dBTP (generated) |
| `data/` | Word-timed transcripts (`*.words.json`, `*.tokens.json`), subtitle cards, EN/FR SRTs |
| `tools/` | Python and shell pipeline: transcription, data fetch, terrain baking, subtitles, render, mux |
| `tools/fr_short.py`, `tools/fr_long.py` | **French subtitle text.** Edit here, then run `tools/build_subs.py` |
| `studio/` | Remotion project (React + Three.js). All scenes, graphics and timing live here |
| `studio/src/short/Short.tsx` | The vertical short: shot list keyed to spoken phrases |
| `studio/src/long/Long.tsx` | The documentary: eight chapters keyed to spoken phrases |
| `studio/src/components/` | Reusable motion-design components (see below) |
| `studio/public/` | Baked textures, rasters, photos and audio used by the renders |
| `deliverables/` | Final exports, thumbnails, cover, SRTs, transcripts, credits, publishing kit |

### Components
- `GeoMap`: d3 orthographic globe that zooms continuously to real relief rasters. Uses Natural Earth, OSM and SRTM data.
- `Terrain` / `TerrainShot`: Three.js terrain built from SRTM elevation with Sentinel-2 imagery, in two datasets: a 44 km regional one and an 8.5 km crater close-up. Includes a GPU gas-flow layer driven by a downhill arrival-time field computed from the real DEM in `tools/geo_render.py`, plus a water shader and village lights.
- `CrossSection`: a south→north profile through Lake Nyos taken from the DEM. It shows dissolved CO₂, pressure, the rising column, the eruption, the gas spilling over the north rim, the degassing pipes and a sampling probe.
- `Village`: an original parallax illustration with night, dusk and dawn states, the gas veil and lights.
- `Science`: the bottle analogy, CO₂ scale, investigation board, definition card and trigger hypotheses.
- `LongParts`: density comparison, deaths-to-scale timeline, case notes, verdict, concept and postcard graphics.
- `Brand`: the FILE #001 folder seal, the 1,700-point memorial field and chapter marks.
- `Type`, `Photo`, `Subtitles`, `FilmLook`, `Shot`: the typography system, archival photo treatments, safe-area subtitles, grain and vignette, and timeline shots with transitions.

**Timing.** `makeCues(tokens)` looks up timestamps from the words actually spoken, for example `at("Lake Monoun")`. If you replace a narration file, re-run the transcription and every animation re-syncs.

## Reproduce from scratch

```bash
# 1 · tools
pip install faster-whisper scipy numpy pillow matplotlib
cd studio && npm install && cd ..

# 2 · data (already included; re-run only if you change areas)
python3 tools/transcribe.py audio/UNKNOWN_FILE_SHORT.mp3 data/short.words.json
python3 tools/transcribe.py audio/UNKNOWN_FILE_LONG.mp3  data/long.words.json
python3 tools/fetch_dem.py nyos_z13 13 6.33 6.66 10.13 10.46
python3 tools/fetch_dem.py region_z10 10 5.2 6.95 9.75 11.25
python3 tools/fetch_dem.py crater_z15 15 6.405 6.47 10.265 10.33
python3 tools/fetch_s2.py s2_nyos_z14 14 nyos_z13
python3 tools/fetch_s2.py s2_region_z11 11 region_z10
python3 tools/fetch_s2.py s2_crater_z16 16 crater_z15
python3 tools/geo_render.py && python3 tools/terrain3d.py && python3 tools/crater3d.py && python3 tools/textures.py

# 3 · subtitles (after editing tools/fr_*.py)
python3 tools/subs.py short && python3 tools/subs.py long
python3 tools/build_subs.py short && python3 tools/build_subs.py long

# 4 · preview / edit interactively
cd studio && npx remotion studio            # compositions: Short, ShortClean, Long, Thumb, Cover

# 5 · render (no GPU needed; ANGLE/SwiftShader)
npx remotion render src/index.ts Short ../renders/short_video.mp4 --gl=angle --muted --crf=14
npx remotion render src/index.ts ShortClean ../renders/short_clean_video.mp4 --gl=angle --muted --crf=14
cd .. && tools/render_long.sh                # chunked + resumable 4K render
tools/finish.sh                              # mux mastered narration + soft subtitles → deliverables/
```

Audio master (narration only):

```bash
ffmpeg -i audio/UNKNOWN_FILE_LONG.mp3 -af "aresample=48000:resampler=soxr,highpass=f=60:poles=2,volume=6.7dB,alimiter=limit=0.78:attack=3:release=60:level=disabled" -c:a pcm_s24le audio/master/NARRATION_LONG.wav
```

## Editing in CapCut

The MP4s contain only the narration. Import the MP4 (or the clean short), add music and SFX on separate tracks, and duck them under the voice. The mastered narration WAVs are also in `deliverables/` in case you prefer to rebuild the audio from scratch.
